# KOVEMU_loadmap

## Core Vision

-   Kovemu is a discovery platform, not a search site.
-   Users should discover Korean creators naturally.

## UX Philosophy

### Korean UX

-   Fast navigation
-   Clear information hierarchy
-   Few clicks

### Western UI

-   Minimal
-   Spacious
-   Typography and imagery focused

**Principle:** Korean usability + Western minimalism.

## Design Rules

-   Avoid portal-style clutter.
-   Keep navigation intuitive.
-   Prioritize discovery over search.
-   Every UI decision should improve exploration.

## Collaboration Rules

-   Debate ideas with evidence.
-   Don't agree automatically.
-   Present alternatives.
-   Optimize for long-term success.
